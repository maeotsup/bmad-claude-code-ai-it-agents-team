# AI Team Bootstrap

This project has the BMAD Claude Code IT Agents Team bootstrap installed but not yet configured.

## Getting Started

Run `/setup` to initialize your AI development team. The setup process will:

1. **Detect your tech stack** (or interview you for new projects)
2. **Generate a complete SDLC pipeline** tailored to your codebase
3. **Replace this file** with a project-specific technical reference

## What You'll Get

- **8 AI agents** — analyst, architect, developer, tester, code reviewer, security reviewer, accessibility reviewer, release manager
- **SDLC workflows** — `/orchestrate`, `/plan`, `/implement`, `/tdd`, `/code-review`, `/verify`, `/pre-pr`, `/issue`
- **Stack-specific commands** — `/build`, `/test`, `/lint`, `/security` configured for your tools
- **Safety guardrails** — hooks that block dangerous commands and auto-lint on file edits
- **Coding rules** — language and framework conventions enforced automatically

## Run Setup Now

Type `/setup` to begin.
